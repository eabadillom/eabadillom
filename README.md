### Proyectos Destacados
* **[Sistema de Inventario, Facturación y Cobranza](https://github.com/eabadillom/gestion-pf):** Control de inventario de un almacén frigorífico. Facturación con timbrado (CFDI 4.0 del SAT). Control de pagos con timbrado (CFDI 4.0 - Complemento de pago 2.0 del SAT).
* **[Sistema de Inventario - Acceso para clientes](https://github.com/eabadillom/gestion-clientes):**
Acceso para clientes al sistema de inventario, registro de solicitudes de retiro de mercancía, consulta de inventario, ingresos, retiros, facturación y pagos.
* **[Sistema de Gestion de Personal](https://github.com/eabadillom/sgp):** Registro de asistencia, vacaciones, incapacidades. Cálculo de nómina (semanal).
* **[Wrapper para envío de correos con Java](https://github.com/eabadillom/gestion-mail):** Proyecto que proporciona un conjunto de clases para facilitar la interacción con la api mail de Java.
* **[Gestión API](https://github.com/eabadillom/gestion-api):** API que permite la interacción de una aplicación móvil con el sistema de inventario, facturación y cobranza.
* **[Gestión Móvil](https://github.com/eabadillom/gestion-movil):** Aplicación Móvil hecha en Flutter, para interactuar con el Sistema de inventario, facturación y cobranza. Ofrece funcionalidad limitada respecto a su versión web (Consulta de entradas, salidas, traspasos, servicios, ordenes de retiro con cancelación, envío de evidencias).
* **[Impresora de CFDI's](https://github.com/eabadillom/cfdi40-printer):** Biblioteca que permite la impresión de un CFDI en su versión 4.0 del SAT, a partir del XML proporcionado por el Proveedor Autorizado de Certificación o directamente por el SAT.
* **[Facturama client](https://github.com/eabadillom/FacturmaClient):** Cliente no oficial para conexión con la API Multiemisor de Facturama.
